# Logic & Beauty

架空のパーソナルジム「Logic & Beauty」を想定して制作したWordPressオリジナルテーマです。
PCではナビゲーション・本文・案内の3カラムを使ったランディングページとして構成しています。

[デモサイトを見る](https://wp002.akiyo-fukuhara.work)

## 主な機能

- レスポンシブ対応の3カラムレイアウトと動画を使ったヒーロー
- スマートフォン用メニューと画面下部の案内バー
- 投稿から取得するキャンペーン表示と料金表示
- Googleカレンダーの埋め込み、設備・トレーナー・料金・FAQなどの紹介
- 投稿・固定ページの確認用テンプレートと404ページ

## セットアップ

1. このリポジトリファイルを wp-content/themes/lb_gym に配置し、WordPressの管理画面でテーマを有効化します。
2. 「設定→表示設定」で、トップページに任意の固定ページを指定します。トップページには front-page.php が使用されます。
3. キャンペーンを表示する場合は Advance Custom Fields (ACF) を有効化し、通常の「投稿」にスラッグ campaign のカテゴリーを設定します。テーマはそのカテゴリーの投稿を1件取得します。
4. キャンペーン投稿に次のACFフィールドを設定します。

   | フィールド名          | 用途                           |
   | --------------------- | ------------------------------ |
   | 'new_trial_price'     | 初回体験料金のキャンペーン価格 |
   | 'new_admission_price' | 入会金のキャンペーン価格       |
   | 'cp_note'             | キャンペーンの注記（期間など） |

5. 必要に応じてカスタムロゴを設定します。デモ用の店舗情報、カレンダー、地図、SNS・相談先のリンクはテンプレート内に記述されています。

## 補足

- このリポジトリは架空サイトのデモです。キャンペーン、料金、店舗情報はサンプルで、href="#" は仮リンクです。
- キャンペーン用のカテゴリー投稿を作らなければ、キャンペーンの表示は省略されます。
- 投稿・固定ページの個別テンプレートは編集内容の確認用で、記事一覧・検索結果への導線は設けていません。
- WordPress管理画面で登録する投稿やロゴはこのリポジトリに含まれていません。
